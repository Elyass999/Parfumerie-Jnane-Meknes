Create a production-ready, mobile-first, French-language UI/UX website for a parfumerie and associated product lines using React (Vite) and Redux Toolkit. Style with CSS variables and CSS-in-JS or CSS modules; use Bootstrap only sparingly for simple utilities. Theme: whitesmoke backgrounds, soft pink accents, and high-contrast accessible text. The app must be fully responsive (phones first), accessible, and fast. Include GSAP for smooth scroll and entrance animations and a modern animated initial loader that displays a brand monogram until the SPA is ready. Provide an assets folder (public/assets/) for videos and images and a data seed folder (src/data/) with French product/category content (approx. 25–40 sample items across the specified brands). Implement the following features and behaviors:

Navigation & pages: sticky responsive navbar (Accueil, Produits, Localisation, Contact) with burger menu on mobile and a small overlay search. Routes for home, products (filterable by category/brand), product details modal/page, gallery, about (À propos), localisation (mini map), and contact form.

Hero: modern animated hero with optional video background from assets, animated brand initial/monogram, French tagline, and primary CTA “Découvrir nos parfums”.

Categories & product sections: brand-organized sections rendered in this order (start with ParaSpace): ParaSpace, Parfum, Forever Brand, The Ordinary Brand, Glasses, Avon Brand, maybeLine Brand, Lattfa parfums. Each category block includes a French title, short description and a horizontal, touch-enabled scroller or carousel of product cards.

Product cards & product view: card shows image, nom, prix, court extrait, and rating placeholder. Buttons: “Commander maintenant (WhatsApp)” which opens a prefilled wa.me URL; “Ajouter au panier” updates Redux cart state. Clicking image/title opens a product modal or detail page with full French description and related products.

WhatsApp ordering: floating WhatsApp widget fixed bottom-right that expands in-place to a compact chat UI with an input and send button; sending opens https://wa.me/<NUMBER>?text=<encoded_msg> where <NUMBER> is provided via environment variable. Every product’s “Commander maintenant” uses a prefilled message including product name and ID. Document where to set the WhatsApp number.

Gallery: masonry/lightbox gallery for popular products and magasin interior images.

Localisation: mini map (Google Maps iframe or Leaflet) showing magasin position, address and opening hours.

Contact: French contact form with fields (nom, email, message) and success/error states.

Footer & extras: modern organized footer with links, socials, newsletter subscription, cookie notice (French) and visible Back-to-top button with smooth scroll.

Performance & UX: lazy-load images, responsive images (srcset), placeholder low-res images, code-splitting with React.lazy + Suspense for heavy sections, touch-friendly controls, large tap targets, keyboard navigation, semantic HTML, aria-* attributes, alt text for images, focus trap in modals.

State & architecture: use Redux Toolkit slices for products, cart and UI. Products slice holds items, categories and filter state; cart slice handles items/totals; ui slice manages loader, modal and WhatsApp widget state. Optionally use RTK Query for an API later.

Data & assets: seed src/data/ with French product objects and categories; put all videos/photos in public/assets/ and reference them from data. Provide a small dev admin toggle to change the WhatsApp number at runtime (dev-only).

Developer quality: include linting/formatting (ESLint + Prettier), unit testing (Vitest or Jest) for critical components, and a README with run/build instructions, where to set the WhatsApp number (env), and how to replace assets/data. Include simple CI workflow for build/test.

Deliverables: a ready-to-run Vite React project that includes the described pages/components, Redux setup, GSAP animations, floating WhatsApp widget, seed French content, an assets folder with placeholders, an accessible loader, and clear documentation explaining where to configure the WhatsApp number and basic deployment steps. Keep all UI text in French.
